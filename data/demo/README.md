## 1. What Data Are Included in This Snapshot?

This `data/demo/` directory provides a verified, deployment-safe snapshot of processed datasets required for the AgriRisk Kenya public demo and portfolio deployment:

1. `forecast_dataset.csv` (~280 KB):
   - **Scope:** 13-year monthly panel (2012–2024; 780 county-months) across the 5 pilot ASAL counties: Turkana, Marsabit, Samburu, Wajir, and Baringo.
   - **Features:** 35 engineered indicators covering CHIRPS rainfall anomalies, MODIS 250m NDVI/VCI vegetation dynamics, WFP staple cereal price momentum, prior IPC states, and Queen contiguity spatial neighbor crisis ratios.
   - **Targets:** Binary crisis classifications for $t+1, t+2, t+3$ forecasting horizons.

2. `model_dataset.csv` (~49 KB):
   - **Scope:** Baseline classification panel used for cross-sectional model benchmarking.

3. `kenya_counties.geojson` (~48 KB):
   - **Scope:** Canonical administrative boundary polygons for Kenya's 47 counties (EPSG:4326), derived from official KNBS/HDX public domain datasets.

4. `manifest.json`:
   - SHA-256 data integrity hashes, source URLs, and transformation timestamps.

## 2. Temporal Nature & Snapshot Limitations

> [!IMPORTANT]
> **HISTORICAL RESEARCH SNAPSHOT — NOT A LIVE OPERATIONAL STREAM**  
> The data in this directory represent an offline, retrospective research panel terminating in **December 2024**. 
> - It does **NOT** represent real-time conditions.
> - Forecast outputs generated by running the demo are historical backtest simulations, not live humanitarian warnings.
> - These data are included to allow reviewers, scholarship panels, and researchers to verify model mechanics and dashboard interactions without executing live web scraping or accessing restricted upstream feeds.

## 3. Data Sources & Attributions

- **Precipitation:** Climate Hazards Center InfraRed Precipitation with Station data (CHIRPS v2.0), UC Santa Barbara.
- **Vegetation:** MODIS (MOD13Q1) 250m 16-day NDVI, NASA Earthdata / USGS LP DAAC.
- **Market Prices:** Vulnerability Analysis and Mapping (VAM) Price Database, UN World Food Programme (WFP).
- **Food Security Ground Truth:** Integrated Food Security Phase Classification (IPC) and National Drought Management Authority (NDMA) historical bulletins.
- **Administrative Boundaries:** Kenya National Bureau of Statistics (KNBS) via Humanitarian Data Exchange (HDX).

No proprietary, personal, or commercially restricted data are stored in this snapshot.
